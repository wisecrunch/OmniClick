Only notes for the connected Google email address are synced. Notes for other mailboxes stay local.

Current JSON files live in OmniClick Notes / Notes. Earlier versions live in Backups. Edits sync shortly after saving and approximately every five minutes while Chrome is running. Disconnecting keeps your notes and Drive files.

Google sign-in setup

Extension ID:

  1. In Google Cloud, enable Google Drive API in your project.
  2. Configure Google Auth Platform branding and audience. If the app is in Testing, add your Google account as a test user.
  3. Create an OAuth client of type Chrome Extension (formerly Chrome App), using the extension ID above as its Item ID. A Web application client will not work with this sign-in method.
  4. In Data Access, add https://www.googleapis.com/auth/drive.file. No full-Drive access or client secret is needed.
  5. Paste the client ID below and download the configured manifest. Replace manifest.json inside your OmniClick extension folder, then reload OmniClick at chrome://extensions and reopen this page.
  6. Click Connect Google Drive and allow access to files created by OmniClick.

For another computer, use the same Google Cloud project and an OAuth client matching that installation's extension ID. Unpacked extension IDs can change when the folder path changes. For one portable ID, use the same published extension or a package with a fixed public manifest key. Export your notes before changing the extension ID.

Saved versions

Each uploaded version is backed up before the current note is updated. If edits conflict, the newest timestamp wins and both versions remain recoverable here. Restore creates a fresh note version and syncs it to your other computers.

Delete notes in OmniClick to sync a deletion. Removing files directly from Drive does not delete the local notes; they can upload again. Backup history is kept until you delete its files from Drive.
