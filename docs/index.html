A toolkit, not another inbox

Keep the useful bits close.

Two focused tools, each with its own toggle. Turn on what helps and leave the rest off.

01 / PRIVATE NOTES

The context email leaves out.

Add a private note above a Gmail thread. Existing notes appear as soon as you open it; empty threads keep a compact Add note button.

  • Autosave, four colors, and a Done checkbox
  • Inbox previews and searchable notes
  • JSON export and import for independent backups
  • Optional Google Drive sync and saved-version restore
02 / AUDIO PLAYER

Listen right where you work.

Play supported MP3 and WAV email attachments inside Gmail. No separate download-and-open routine for a quick listen.

  • Player controls next to supported attachments
  • Support for GSM-encoded WAV phone recordings
  • Audio decoding happens in your browser
  • Enable or disable independently from notes
Your notes. Your choice.

Local first.
Cloud when you want it.

Notes stay in your browser unless you connect Google Drive. With sync enabled, OmniClick writes visible note files and saved versions directly to your own Drive. It does not send your notes or audio to a developer-operated server.

Get started

A few steps. Then fewer clicks.

The current version is installed from source. A Chrome Web Store listing is not required for this setup.

01

Download and unzip

Download the repository ZIP and extract it. The extension folder is the one containing manifest.json.

02

Load in Chrome

Open chrome://extensions, turn on Developer mode, select Load unpacked, and choose that folder.

03

Make it yours

Refresh Gmail. Open OmniClick’s popup and toggle on the tools you want. Notes work locally without Google Drive setup.

How do I enable Google Drive sync?

Open Google Drive sync in the extension popup and follow its Google sign-in setup. Source installations require a Google Cloud project, the Drive API, and a Chrome Extension OAuth client matching the extension ID. See the repository setup guide. Drive access is limited to files created or explicitly authorized for OmniClick.

Will notes appear in the Gmail mobile app?

This is a desktop Chrome extension. It does not add notes to the official Gmail mobile app. Drive sync shares notes between configured desktop installations; it does not install a mobile Gmail interface.

What happens when I delete a note?

Deleting a note in OmniClick removes it from the notes list and syncs a deletion marker if Drive is connected. Earlier uploaded versions remain in Drive’s Backups folder until you delete those files. Export a backup before removing the extension.

Where can I get help?

Use the GitHub issue tracker for questions and bug reports. Issues are public, so leave out notes, email contents, credentials, and other private information.
