1. What OmniClick provides

OmniClick offers optional tools for Gmail, including private thread notes, supported audio attachment playback, and Google Drive note sync with backups and restore controls. Features can change as the project develops. The current source version is provided without a usage fee and is installed through Chrome’s developer-mode workflow.

Drive sync requires a suitable Google Cloud OAuth configuration and your Google authorization. It is not automatically enabled by installing the extension. This desktop extension does not provide an interface inside the official Gmail mobile app.

4. Backups, sync, and availability

Keep independent backups of important information. Local browser storage can be removed, Google authorization can expire or be revoked, and network failures or third-party changes can interrupt syncing. When multiple versions conflict, the extension uses note timestamps and a deterministic tie break to select the current version, while preserving uploaded versions for recovery. This is not a guarantee that every unsaved edit can be recovered.

Deleting a note can leave deletion markers and earlier saved versions. Disconnecting or uninstalling does not remove files already saved in Drive. See the Privacy Policy for steps to remove all copies. You are responsible for confirming that any needed export or backup completed successfully.
